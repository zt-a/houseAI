Цель работы

Разработать модель машинного обучения для прогнозирования стоимости квартир в городе Бишкек на основе данных с сайта housekg.kg.

Как готовили датасет

  1. Сбор данных - SQLite база housekg.db, таблица properties
  2. Фильтрация - только квартиры в Бишкеке, удаление пустых цен/площадей
  3. Очистка выбросов - площадь 15-250 м², цена 1-40 млн сом, цена за м² 10-200 тыс сом
  4. Feature Engineering - возраст здания, соотношения площадей, расстояние до центра по Haversine
  5. Геокластеризация - KMeans по координатам (15 кластеров)
  6. Парсинг адреса - извлечение микрорайонов из поля address (т.к. district был пуст)
  7. Парсинг JSON - флаги удобств из features_json
  8. Target Encoding - кодирование районов с KFold кросс-валидацией

Машинное обучение

  • Ансамбль - CatBoost + LightGBM с взвешенным блендингом
  • Трансформация - обучение на log1p(price), предсказание через expm1
  • Кросс-валидация - 10-fold KFold для объективной оценки
  • Оптимизация - Optuna для подбора весов ансамбля
  • Оптимальные веса - CatBoost 70.7%, LightGBM 29.3%
