Схема работы градиентного бустинга в проекте

Прогнозирование цен на квартиры в г. Бишкек | CatBoost + LightGBM

1. Принцип градиентного бустинга (последовательное построение деревьев)

Исходные данные
Площадь, этаж, район, год постройки и др.
↓
Дерево 1
Грубое предсказание F1(x)
→
Ошибка 1
Остатки (разница с реальной ценой)
↓
Дерево 2
Исправляет ошибки дерева 1
→
Ошибка 2
Меньше, чем у дерева 1
↓
Дерево 3, 4, ..., N
Каждое следующее исправляет ошибки предыдущих
↓
Итоговая модель
Сумма всех деревьев = точное предсказание
F(x) = F₁(x) + α·h₁(x) + α·h₂(x) + ... + α·hₙ(x)
где h₁,h₂,...,hₙ - решающие деревья, α - вес каждого дерева

3. Сравнение моделей в нашем проекте

Линейная регрессия (бенчмарк)

Принцип: Прямая зависимость

Формула: y = w₁*x₁ + w₂*x₂ + ... + b

Особенность: Считает, что каждый признак влияет независимо и линейно

Применение: Мы использовали только для сравнения

❌ Менее точна для сложных зависимостей

CatBoost

Тип: Градиентный бустинг

Разработчик: Яндекс

Сильная сторона: Отлично работает с категориальными признаками (район, состояние)

Особенность: Умно обрабатывает категории без ручного кодирования

✓ Вес в ансамбле: 70,7%

LightGBM

Тип: Градиентный бустинг

Разработчик: Microsoft

Сильная сторона: Быстрый, строит деревья по листьям

Особенность: Видит данные с другой точки зрения, дополняет CatBoost

✓ Вес в ансамбле: 29,3%

5. Преобразование данных в числа

Числовые признаки
  • Площадь, этаж, год - оставлены как есть
  • Возраст дома - посчитан: 2026 - год постройки
  • Расстояние до центра - формула Haversine по lat/lng
  • Соотношения - floor_ratio, area_per_room и др.
Категориальные признаки
  • Микрорайон из адреса - парсинг регулярными выражениями
  • Состояние, отопление - переданы в CatBoost как категории
  • Target Encoding - средняя цена по району
  • KMeans кластеры - географические кластеры
Бинарные и прочие
  • Удобства из JSON - 0 или 1 (лифт, балкон)
  • Первый/последний этаж - бинарные признаки
  • log1p(price) - логарифм цены при обучении
  • expm1(pred) - обратное преобразование
