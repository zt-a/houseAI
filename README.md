# HouseKG Price Prediction (Бишкек, квартиры)

Модель для предсказания цены квартир в Бишкеке на основе объявлений с housekg.kg.

## Данные
- Источник: `housekg.db` (таблица `properties`)
- Выборка для обучения: квартиры в Бишкеке, после фильтрации выбросов — **1167** объявлений
- Целевая переменная: `price_som`

## Структура проекта
```
houseAI/
├── data/
│   ├── raw/           # копия БД (не трогать оригинал)
│   └── processed/     # очищенные датасеты
├── models/            # обученные модели CatBoost
├── src/
│   ├── config.py      # константы и пути
│   ├── prepare.py     # загрузка из SQLite, чистка, фичеинжиниринг
│   ├── train.py       # обучение v1
│   ├── train_v2.py    # обучение v2 (улучшенная версия)
│   └── predict.py     # пример инференса
└── requirements.txt
```

## Быстрый старт

```bash
# Установка зависимостей
pip install --break-system-packages -r requirements.txt

# Подготовка данных
python src/prepare.py

# Обучение (v1)
python src/train.py

# Обучение (v2 - лучше)
python src/train_v2.py

# Проверка предсказаний
python src/predict.py
```

## Ключевые фичи
- `total_area`, `rooms_num` - площадь и комнаты
- `floor_num` / `floors_total_num`, `floor_ratio` - этажность
- `year_built_num`, `age` - возраст дома
- `dist_bishkek_center_km` - удалённость от центра
- `district_cat`, `condition_cat` - локация и состояние
- `features_json` флаги (лифт, балкон и др.)

## Примечания
- Обучение на логарифме цены (`log1p`), обратное преобразование `expm1`
- Категориальные фичи обрабатываются напрямую CatBoost
- В основном Бишкек; для других городов нужна отдельная модель
